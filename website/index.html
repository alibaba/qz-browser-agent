Agent-friendly.

Let your agent delegate browser tasks to qz.

Requires Node.js 22+ and Chrome on the same machine, with the qz extension and a model configured.

Install the CLI

Connect once. Start tasks from your terminal.

CLI
npm install --global qz-browser-agent
qz connect

Also available via npx --yes qz-browser-agent@latest. For MCP, run qz mcp after connecting to get the connection URL.

CLI & MCP guide

Install the Skill

Let your coding agent delegate browser tasks to qz.

SKILL
npx skills add alibaba/qz-browser-agent -g

Then ask your agent: “Use qz to compare these three product pages and save a sourced table.”

Read the Skill

Local storage. Your model.

Sessions, Skills, and collected data are stored in your browser. Use a compatible model service with tool calling, a local model server, or OpenAI Codex with ChatGPT sign-in.

Task context is sent to your configured model service. Skills and MCP connections may exchange data with services you configure.

Install qz

Install from the Chrome Web Store, then connect your model service or sign in with ChatGPT.

Add to ChromeManual install · GitHub Release
  1. 01

    Add to Chrome

    In the Chrome Web Store, click “Add to Chrome” and confirm the installation.

  2. 02

    Connect your model

    Open qz Settings. Choose a provider and enter its credentials, or choose OpenAI Codex and sign in with ChatGPT. Select a model and save.

  3. 03

    Give it a task

    Open the side panel and describe what you want to do. You can adjust the task while it runs.
